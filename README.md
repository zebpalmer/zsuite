# zsuite
Just a place to throw common code I use across my various personal python projects

## Optional extras

- `zsuite[mongo]` — `zsuite.mongodb`: `get_mongo`, `get_mongo_client`, `get_mongo_db`, configured from `MONGO_*` config vars
- `zsuite[webservice]` — `zsuite.webservice`: `HALOFlask`, `AuthManager`, `auth_required`, `public_endpoint`,
  `HealthService`, `sanitize_mongo_query`
- `zsuite[all]` — both
